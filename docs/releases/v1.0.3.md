## ACRA v1.0.3

### Mises à jour cohérentes (#185)
- La version installée est comparée correctement à la dernière release : plus de fausse alerte « mise à jour disponible » quand l'instance est à jour.
- Deux canaux : **stable** (branche `stable`, dernière version validée) et **bêta** (branche `main`, dernière version validée + évolutions suivantes).
- `scripts/update.sh stable|beta` : sauvegarde de la base, mise à jour en avance rapide, reconstruction, contrôle de santé, commande de retour arrière en cas d'échec.
- Bouton **« Mettre à jour »** (Administration → Version) pour les instances auto-hébergées : `scripts/update-agent.sh --install` une seule fois sur le serveur (la tâche planifiée est ajoutée automatiquement).

### Autres évolutions
- Méthodes ISO/IEC 27005, ISO 31000, NIST SP 800-30 : échelle de l'organisation, évaluation sur niveau actuel et appétit, propriétaire du risque, rapport PDF/Excel par méthode.
- Questionnaire de qualification : risques proposés / imposés.
- Organisations : renommer, déplacer, supprimer (vide) ou fermer avec confirmation (#186).
- Saisie des ateliers : le formulaire d'ajout s'ouvre en haut de la liste (#188).
- Connecteurs d'entités REST/LDAP ; correctifs sécurité (gel à la validation MCP, export d'organisation journalisé, import Excel).
- Module optionnel « profils opérationnels » (désactivé par défaut, refonte prévue en 1.0.4).

### Mettre à jour une instance antérieure (une seule fois)
```bash
git fetch origin && git checkout stable && git pull   # ou rester sur main pour la bêta
scripts/update-agent.sh --install                      # facultatif : active le bouton
docker compose up -d --build
```
En production, ajouter `-f docker-compose.yml -f docker-compose.production.yml` aux deux dernières commandes. Ensuite : `scripts/update.sh stable` ou le bouton.
